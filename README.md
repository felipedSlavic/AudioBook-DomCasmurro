Player de audiobook do clássico **Dom Casmurro** de Machado de Assis.  
A aplicação reproduz os capítulos em áudio com navegação entre faixas e interface temática.

---

## ✨ Funcionalidades

- ▶️ Play / Pause do capítulo atual
- ⏭️ Navegação para o próximo capítulo
- ⏮️ Navegação para o capítulo anterior
- 🔁 Volta automaticamente ao Capítulo 1 ao chegar no último
- 📚 10 capítulos em áudio disponíveis
- 🎨 Temas visuais: Azul Inverno, Estelar, Meia-Noite, Rosa Claro e Verde Cipreste

---

## 🛠️ Tecnologias

| Tecnologia | Uso |
|---|---|
| HTML5 | Estrutura e elemento `<audio>` nativo |
| CSS3 | Layout Flexbox, gradiente e temas visuais |
| JavaScript | Manipulação do DOM, controle de áudio e navegação entre faixas |

---
